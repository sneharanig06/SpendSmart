SpendSmart – Student Expense Tracker

About the Project

SpendSmart is a student expense tracking and budget management web application designed to help students manage their personal finances.

It helps users record expenses, monitor spending patterns, manage budgets and make better financial decisions.

Problem Statement

Students often struggle to track their daily expenses and manage their monthly budgets. SpendSmart aims to provide a simple platform to monitor expenses and improve financial awareness.

Features

- User registration and login
- Expense tracking
- Expense categorization
- Budget management
- Spending summaries
- Dashboard for monitoring expenses
- Docker-based application containerization
- Automated CI/CD workflow using GitHub Actions

Technologies Used

Frontend:

- JavaScript

Backend:

Project Objective

To help students develop better financial habits through expense tracking, budget monitoring and spending analysis.
